System Configuration & Privacy Policies

Admin Control

Manage data retention auto-purge windows, Re-ID embedding thresholds, DPDP Act 2023 privacy settings, and feature flags.

🛡️ Privacy by Design (DPDP Act 2023)

Data Retention Window (Auto-Purge) 30 Days

Embeddings, evidence crops, and events older than this window are permanently purged by the daily maintenance daemon.

Facial Recognition Module OFF BY DEFAULT

Facial embedding generation is strictly disabled. Only appearance-based Re-ID (clothing & torso features) is active. To enable facial recognition for enrolled staff with verified consent, configure FACE_RECOGNITION_ENABLED=true in .env.

Default Anonymisation (Viewer Role)

Apply Gaussian blur to faces and thumbnails for non-admin viewers.

⚙️ Detection & Anomaly Thresholds

Re-ID Cosine Matching Threshold 0.68

Cosine similarity cutoff above which a recurring visitor profile is merged rather than creating a new profile.

Default Loitering Alarm Threshold 60 Seconds

Continuous presence in a zone exceeding this threshold flags a high-priority loitering anomaly alert.

Active AI Models:

Object Detection: yolo26n.pt (Ultralytics)

Multi-Object Tracking: ByteTrack (persist=True)

Vector Search Engine: Neon pgvector (HNSW cosine)
